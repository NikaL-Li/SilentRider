## 工程决策

### 为什么前端单文件

- 弱网、低端安卓机也能打开；
- 不需要 Node 构建链；
- 方便复制/离线分发。

### 为什么后端只用标准库

- 云服务器安装成本低；
- 无 pip 依赖也能跑；
- OCR/图片压缩作为可选增强，失效时自动回退。

### 为什么 OCR 从本地换到云

本地 Tesseract 对长截图约 4 秒，且中文小字不稳定。
最终采用腾讯云 `RecognizeAgent`，截图压缩到 1800px 后约 1.3 秒；本地 Tesseract 保留兜底。

### 为什么最终用 Cloudflare Tunnel

JD Cloud 会按未备案域名 Host/SNI 拦截入站请求，Cloudflare Tunnel 从源站主动出站，绕过该限制。

## 已知限制

- Web Speech API 依赖浏览器，Safari/微信内置浏览器兼容性有限；
- OCR 依赖云服务配额，截图包含隐私信息；
- 电话外放受设备音量与系统策略影响；
- 域名依赖 Cloudflare Tunnel 进程存活。
